# Descripción del Proyecto

El presente proyecto consiste en el desarrollo de un Sistema PETI (Plan Estratégico de Tecnologías de Información) empresarial, diseñado para permitir a las organizaciones gestionar y elaborar sus estrategias tecnológicas mediante módulos interactivos, dashboards y matrices estratégicas.

El sistema fue desarrollado bajo una arquitectura Full Stack utilizando frontend y backend separados, permitiendo persistencia real de datos, autenticación de usuarios y control de acceso por roles.

El objetivo principal es digitalizar y automatizar el proceso de elaboración del PETI, facilitando la administración estratégica de la empresa.

# Mejoras Implementadas para el Examen

## 1. Bloqueo Secuencial de Módulos PETI

Se implementó un sistema de validación secuencial donde el usuario no puede acceder a módulos posteriores si no completa previamente el módulo anterior.

### Funcionalidades
- Validación automática de progreso
- Bloqueo de acceso a módulos incompletos
- Indicadores visuales de avance
- Control del flujo estratégico PETI

### Beneficios
- Mejora la organización del proceso PETI
- Evita inconsistencias en la información
- Garantiza el cumplimiento ordenado de las etapas

---

## 2. Sistema de Exportación de Datos

Se agregó la funcionalidad de exportación de información estratégica del sistema.

### Formatos disponibles

### Funcionalidades

# Instalación y Ejecución Local

## Clonar repositorio

```bash
git clone https://github.com/UPT-FAING-EPIS/PE_II_EXAMEN_PRACTICO_Vargas.git
```

---

## Instalar dependencias

```bash
npm install
```

---

## Configurar variables de entorno

```bash
copy .env.example .env
```

---

## Ejecutar el sistema

```bash
npm run dev
```

---

## Abrir en navegador

```text
http://localhost:3000
```
